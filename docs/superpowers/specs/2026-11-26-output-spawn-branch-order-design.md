# 产出拉子批（方案 A）· 与并行组（方案 B）并存

**日期：** 2026-11-26  
**状态：** 已确认（一期：手动生成；自动开可选）
**范围：** 配方产出行下游关系 + 批次产出过账后生成支线子指令

## 1. 目标

主线与支线配成**两张配方**时：主线登产出（如渣）后，可**手动 / 自动**生成支线批次指令，投料侧预填该产出批；批号可不同于主线。

与方案 B（同配方并行组）并存：近端同批用 B，另线另配方用 A。

## 2. 配方产出行配置

| 字段                     | 说明                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| `downstreamSpawnEnabled` | 是否启用生成下游指令                                                 |
| `downstreamFormulaIds`   | 下游生效配方 id **列表**（可多选）；兼容旧字段 `downstreamFormulaId` |
| `downstreamSpawnMode`    | `manual` 手动生成 / `auto` 过账后自动开                              |

- **手动生成**：登产出后，在「产出与追溯」点「开支线指令」才开子令；多个下游时弹窗选配方。
- **过账后自动开**：产出过账成功即开子令；**仅当下游恰好 1 个**时可选；多个下游强制手动。

主产品行一般不配；副产/废弃/回收常配。下游配方主产品可为中间体或洗涤后物料。

## 3. 快照与产出行

下发时 `expectedOutputs` 带上上述字段。`postOutput` 写入 `order.outputs[]` 时拷贝配置；生成子令后写：

- `branchOrderId` / `branchBatchNo`
- 子令：`parentOrderId`、`parentOutputId`、`branchSourceBatchId`

## 4. 手动生成规则

1. 产出行已有 `batchId`（去向会建批），且启用下游、有下游配方。
2. 尚未挂 `branchOrderId`。
3. 生成待下发子令：数量=本行产出量（可改）；理论投料按下游配方缩放，并把与产出物料匹配的投料行标 `preferredBatchId`。
4. `sourceLabel`：`支线 ← {主线批号}`。

`auto`：过账成功且满足 1～2 时自动调用同一套生成逻辑（失败只记日志/提示，不回滚产出）。

## 5. 待开支路

可从主线产出行操作「开支线指令」；列表级「待开支路」= 启用下游且有批次、无 `branchOrderId` 的产出行（一期可挂在批次产出与追溯操作列）。
