# 工艺路线拓扑（方案 A）

**日期：** 2026-11-26  
**状态：** 已落地（一期 MOCK + 编辑/详情）  
**范围：** 工艺路线由离散格子升级为「主线 + 支线」工序流；本期**不考虑产线关联**。  
**背景：** 现场图（如沉锂线）主线分出洗涤支线、多路汇压滤，压滤不在主线；现有步号×并行行网格表达不了，MOCK 还把压滤误塞成主线第 3 步。

## 1. 目标

- 工艺路线能配置并展示：**主线工序流 + 支线分出/汇合**，节点挂**工序**与**候选设备**。
- 支持**多条支线汇到同一节点**，且该汇合点**可以不在主线上**（如压滤）。
- 旧格子路线可继续打开；新编辑与沉锂 MOCK 走拓扑。
- 配方仍挂路线；**批次执行顺序仍以配方工艺阶段为准**（本期拓扑不直接当步骤引擎）。

## 2. 非目标（本期不做）

- 产线工段与路线节点互相关联 / 双图画同步。
- 自由拖拽画布（点边任意连）。
- 用路线拓扑替换配方阶段门禁与下发快照引擎。
- 共享设备强锁（压滤占机排队）。

## 3. 数据模型

路线增加 `layout: 'topology' | 'grid'`（缺省：有 `nodes` 用 topology，否则 grid）。

### 3.1 节点 `nodes[]`（类似产线 `stations`，但挂工序）

| 字段                | 含义                                                 |
| ------------------- | ---------------------------------------------------- |
| `id`                | 节点 id                                              |
| `seq`               | 排序号（主线连续；支线也可有序，仅用于列表与预览）   |
| `pathKind`          | `main` 主线 / `branch` 支线                          |
| `branchName`        | 支线名称（仅支线；同名支线可多节点串成一条支线）     |
| `processId`         | **工序** id（必填）                                  |
| `name`              | 展示名，默认带出工序名，可改                         |
| `equipmentIds`      | 候选设备（可多选）                                   |
| `equipmentCategory` | 可选，设备分类                                       |
| `forkAfterNodeId`   | 支线：从哪个节点之后分出（通常主线节点）             |
| `joinToNodeId`      | 支线：汇入哪个节点（主线或**共享汇合节点**，如压滤） |
| `joinMode`          | 可选：该节点作为汇合点时 `all` / `any`（默认不强制） |
| `edgeOutLabel`      | 可选：离开本节点的默认物流标签（液/渣/锂盐），预览用 |

说明：

- **压滤**建为 `pathKind: branch`（或单独 `pathKind: sink` 若实现时更清晰；对外文案仍叫汇合点），挂在某条洗涤支线末或作为独立汇合节点；其余洗涤支线的 `joinToNodeId` 都指向它。
- **不再**用「同一 stepNo 多行」表示液/渣并行。

### 3.2 与旧 `grid` 共存

| `layout`   | 编辑              | 设备候选收集                     |
| ---------- | ----------------- | -------------------------------- |
| `grid`     | 原网格编辑器      | `collectRouteEquipmentIds(grid)` |
| `topology` | 节点表 + 拓扑预览 | 汇总各节点 `equipmentIds`        |

迁移：打开旧路线不强制改；提供「转为拓扑」时把每列主行变成主线节点，并行行变成支线（`forkAfter` = 前一主线列，`joinTo` = 下一主线列），不保证语义完美，需人工改。

## 4. 编辑与展示

- 编辑页：**节点表格**（路径、工序、设备、分出、汇入）+ **拓扑预览**（复用/仿产线 `ProductionLineTopologyPreview` 思路）。
- 列表/详情：拓扑摘要文案，如  
  `主线：一次净化→二次浆化→沉锂→…；支线：氟渣洗涤→压滤；钙镁渣洗涤→压滤；…`
- 校验：主线至少 1 节点；支线必须有分出点与汇入点；汇入点必须存在；工序必填；设备可选但建议填。

## 5. MOCK：沉锂相关路线 `GYLX0012`

按现场图（不考虑产线）：

**主线（不含压滤）：**  
一次净化 → 二次浆化 → 沉锂 → 脱碳 → 除磷 → MVR浓缩 →（包装/钠盐视现有种子裁剪）

**支线：**

| 支线       | 分出点后 | 节点                    | 汇入                                     |
| ---------- | -------- | ----------------------- | ---------------------------------------- |
| 氟渣洗涤   | 一次净化 | 氟渣洗涤 →（可含）      | **压滤**                                 |
| 钙镁渣洗涤 | 二次浆化 | 钙镁渣洗涤              | **压滤**                                 |
| 锂盐洗涤   | 沉锂     | 锂盐洗涤 → 离心（可选） | 视种子：离心回液可标回主线脱碳；固相另述 |

**压滤**：独立汇合节点，不在主线 seq 链上；三路洗涤 `joinToNodeId` → 压滤。

旧「第 3 步压滤/洗渣」「第 5 步二次浆化‖洗渣」格子表述废弃。

## 6. 与配方 / 批次

| 能力                 | 本期                                                                              |
| -------------------- | --------------------------------------------------------------------------------- |
| 配方挂路线           | 不变                                                                              |
| 阶段候选设备         | 拓扑路线：按阶段工序名/`processId` 匹配节点设备并集；匹配不到则不限制或沿用原逻辑 |
| `routeSnapshot`      | 仍来自**配方阶段**，不改成跑拓扑节点                                              |
