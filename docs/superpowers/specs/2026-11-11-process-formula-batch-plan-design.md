# 流程型 MES：配方、批次指令与批次库存

**日期：** 2026-11-24（对照当前前端实现回写；文件名沿用 11-11 初稿路径）  
**仓库：** i-doms-web（`MES-for-PROCESS`）；小程序规则见第 12 节，单据仍在 Web 审核  
**状态：** 与当前原型对齐；文中标注「未落地 / 二期」的项尚未实现

当前系统按离散件制造建模：母件用几件子件、多层 BOM、下料尺寸、件工单、齐套、计件工资，批次只表示「这批货属于哪张销售单」。流程型生产是**一张配方对应一次配料或一个槽次**，数量是批量（kg、L 或 m³）。库存按批次状态放行；效期是否参与放行由物料决定。储罐是否保住批次身份由储罐自己的配置决定。

连续运转的湿法线仍用槽次指令表达一个槽的一次进料，用混罐表达中转和母液回流。日计划是投料计划，不是当天一张指令、做完再关。回收率按期间金属平衡看，不要求当天投入当天产出。

单据尽量沿用现有菜单，改规则、改对象，不平行再做一套单据。路由一期不改，避免已打开页签失效。

同一套能力覆盖配料和多段反应，靠配置组合，不按单个工厂写死流程。

| 配置       | 配料（食品、涂料、日化、精细化工）  | 多段反应（浸出、净化、反应釜串联）                           |
| ---------- | ----------------------------------- | ------------------------------------------------------------ |
| 批量规则   | 整批：每张指令等于基准批量          | 槽次：可先占罐，执行中补数量，不超过罐容                     |
| 计划       | 按需求向上取整生成整批指令          | 按线维护投料计划。日目标不拆成关闭型工单                     |
| 投料计算   | 投料量与配比二选一 + 按含量折算开关 | 化验公式投料未落地；前段实加可以不等于理论量                 |
| 过程不合格 | 留在本指令补加、复检，直到放行      | 前段只记录。后段和入库不合格不能转出                         |
| 储罐       | 默认保住批次身份                    | 反应槽保住身份；中转罐、母液罐、循环罐按现场选保住身份或混罐 |
| 得率       | 质量得率                            | 指令上可结主元素收率。周、月看期间金属平衡                   |
| 效期       | 按物料打开                          | 多数物料关闭                                                 |

## 1. 分期

### 第一期（已落地 / 进行中）

1. 配方可发布（版本、发布、生效）；产出角色含主/联/副/**回收料/废弃物**；指定产出工序；**去向在执行过账时选择**（待判定/仓库/储罐/回用/再提/废弃），配方表不维护 destination。
2. 按基准批量生成指令与理论投料/预期产出快照；连续线投料计划（月/周/日）挂产线。**槽次数量先空、完结确认卡罐容：未落地。**
3. 投料指定原料批次过账。计算：投料量 | 配比 + 可选按含量折算。**化验公式投料：未落地。**
4. 过程化验挂工序/阶段方案；硬门禁挡「确认本步」（仅过程检）。产出化验挂产出行，过账时生成检单；回用/再提受产出化验硬门禁约束。
5. 产出过账可入库/入罐/回用/再提/废弃；结质量得率差。**主元素收率、期间金属平衡：未落地。**
6. 批次有状态（含待判定/待回用/待再提等扩展）。效期按物料启用参与拦截。
7. 储罐/料仓罐容与库存方式规则保留（与库存域实现同步）。
8. 返工（已入库再加工）与**再提指令**分流；回用走回流投料。
9. 采购/外协收货 → 待检 → 放行或让步后可投料；外协流程型发收回保留。

不做工程变更、包装单元投诉反查。小程序见第 12 节。

## 3. 产品与物料

现有计划策略是 `mto` / `mts` / `mto_mts`（`src/mock/productInfoOptions.js`）。改为两项：

| 值      | 文案     | 含义                                               |
| ------- | -------- | -------------------------------------------------- |
| `batch` | 按批生产 | 销售或手工需求驱动，生成批次指令                   |
| `stock` | 备库存   | 成品或中间体低于最低库存时，由库存预警生成批次计划 |

已存 `mto` 迁到 `batch`，`mts` 与 `mto_mts` 迁到 `stock`。只有「备库存」必填最低库存。

主单位用重量或体积（kg、L、m³）。第二单位、储存条件可维护；空值显示 `—`。保质期、复验期仅在启用效期时必填。产品主数据不维护含量，也不单设密度。重量和体积要换算时，在辅助单位上填默认换算率。配方、入库、发货不读密度。

成品、联产品和副产品的实测含量不固定，不做成含量 SKU。含量只记在批次上。合格档次（如工碳、电碳）工艺和标准都不同时，各建一个产品；同一档次里 98.6% 和 99.1% 仍是这个产品。计划和配方指向产品，不指向某个含量点。销售按批次实测含量或档次取价。

| 字段     | 规则                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------- |
| 启用效期 | 否为默认。为是时，批次写失效日期；投料和发货拦截过期批次，并按近效期先出                                    |
| 检验项   | 来自检验项库。一个物料可有多项。批次上按检验项记实测值                                                      |
| 供应型态 | `自制` 本厂产线；`外购` 直接采购；`外协` 本厂有配方/规格，原料发出外厂加工后收回；`客供` 客户来料不产生采购 |

工时配置、下料结算、图号、材质改为可空，保存不拦截。

未启用效期的物料没有过期状态。投料和发货只看合格状态，出库顺序按入库时间。

## 4. 配方（原产品 BOM）

菜单与详情标题改为「配方」。状态机不动：待发布 → 生效 → 归档。同一物料同时只有一个生效版本。发布、升版、归档沿用 `productBomStore`。

### 4.1 表头（当前实现）

| 字段     | 规则                                                             |
| -------- | ---------------------------------------------------------------- |
| 配方类型 | `standard` / `trial` / `customer`                                |
| 基准批量 | 必填，大于 0                                                     |
| 理论得率 | 0～1。理论产出 = 基准批量 × 理论得率，回写主产品产出行预期数量   |
| 工艺路线 | 可选；用于设备候选与引用，**不替代**配方内嵌工艺阶段作为执行顺序 |
| 默认配方 | 布尔                                                             |

**未落地：** `sizing`（整批/槽次）、`reactorTankId`、主元素检验项。槽次「数量先空 / 待确认 / 卡罐容」见批次指令节，当前主路径下发即带确认数量。

### 4.2 产出行（当前实现）

| 字段     | 规则                                                                      |
| -------- | ------------------------------------------------------------------------- |
| 角色     | `main` / `co` / `by` / **`recycle` 回收料** / **`waste` 废弃物**          |
| 物料     | 必填；主产品必须等于配方所属物料                                          |
| 预期数量 | 相对一个基准批量                                                          |
| 产出工序 | 对应配方工艺阶段 `stepNo`                                                 |
| 产出化验 | 勾选启用（仅成品检/产出化验）+ 门禁；写入阶段 `assaySchemes` 中成品检方案 |
| 去向     | **不在配方维护**；执行过账时选 disposition                                |

执行时 disposition：`pending_decide` 待判定、`warehouse` 入仓库、`tank` 入储罐、`reuse` 回用、`reextract` 再提、`scrap` 废弃。

**未落地：** `elementBucket`（元素去向）。

同一步可过账多条产出（如卤水与渣），不另开指令。

### 4.3 投料明细（当前实现）

去掉母件用量、下料尺寸、子件 BOM。

| 字段          | 规则                                                            |
| ------------- | --------------------------------------------------------------- |
| 物料          | 必填                                                            |
| 投料量 / 配比 | 二选一                                                          |
| 损耗、允差    | 比例                                                            |
| 按含量折算    | `convertByContent` 开关                                         |
| 配方含量      | 开启时必填（0～1）。**仅生成理论投料**；编辑/详情展示理论投料列 |
| 投料顺序      | 正整数                                                          |
| 所属阶段      | 可指定工艺阶段                                                  |

理论投料：

- 投料量：`投料量 × (1 + 损耗)`
- 配比：`基准批量 × 配比 × (1 + 损耗)`
- 按含量折算：上式 ÷ **配方假定含量** → 写入批次 `theoreticalFeeds.qty`
- 现场实投含量：手填优先，否则批次含量；**不以配方回落**；开折算且缺含量不能过账

**未落地：** `calcMode: assay` 化验公式投料、`referenceQty`/`calculatedQty` 三分账、计划外投料字段。

### 4.4 不再展开多层

下达、打印、详情只展示本配方这一层。中间体做成独立物料、独立配方。父配方投料行只引用中间体物料，不挂子配方，下达时也不自动拆中间体指令。

上一指令的产出进入仓库或储罐后，下一指令把它当作原料批次领用。

昨天的料还在后段、今天已经在前段投新料，用多张执行中的槽次加上混罐衔接，不用一张指令串起整条线。

历史树形 BOM 不迁移。本地数据版本号加一，旧结构丢弃并重新种子化。

## 5. 储罐与库存方式

位置类型仍为货位、储罐、料仓。储罐和料仓增加：

| 字段     | 规则                                     |
| -------- | ---------------------------------------- |
| 罐容     | 必填，大于 0                             |
| 运行上限 | 可空，大于 0 且不超过罐容。空则只卡罐容  |
| 单位     | 与罐内物料主单位一致                     |
| 库存方式 | `identity` 保住批次身份，或 `blend` 混罐 |

液位等于罐内结存数量，不能超过罐容。超过罐容的转入、产出过账都拒绝。结存超过运行上限时允许过账，并给出提示。连续线常用罐容的大约三分之二作为运行上限，留出约三分之一空位。

**保住批次身份。** 罐内按批次分列。转移必须指定源批次和数量。部分转移时拆出新批次，继承状态、含量、检测项、效期，并记下直接父批次。反应槽使用这种方式，槽次指令的在制批量占着这台罐，直到产出转出。

**混罐。** 转入不保留来源批次在罐内的独立身份。罐存是一个结存数量，另记直接来源：来源批次、数量、转入时间。从混罐领出时生成新批次：

- 数量为本次领出量
- 状态取这些直接来源里最严的一档：有待检则为待检，否则有让步接收则为让步接收，否则为合格；来源里有不合格时禁止领出
- 检测项按来源数量加权
- `parents` 只记录这一层直接来源
- 启用效期时，失效日期取来源里最早的一个

混罐的来源如果本身也是混罐领出批次，追溯展示到该领出批次为止，不再往更早的来源展开。循环罐、母液罐、汇流罐用混罐；需要分批存放的配料罐、成品罐用保住身份。两种方式可以出现在同一租户的不同储罐上。

## 6. 工艺路线与工序（当前实现）

配方可挂路线；**执行顺序与门禁以配方工艺阶段快照（`routeSnapshot`）为准**。路线编辑器仍可有网格/并行（离散遗留），流程型执行不依赖「同一步多工序」。

| 现场现象                   | 处理                                     |
| -------------------------- | ---------------------------------------- |
| 同槽次先后反应、取样、过滤 | 配方工艺阶段先后；上一步确认后继续下一步 |
| 同一步滤液与滤渣分走       | 同一步多条产出行；后续另开指令领用       |
| 酸法/水浸/火法不同制法     | 各一张配方                               |
| 多台罐同时生产             | 多张批次指令                             |

**工序配置：** 编码、名称、分类、说明、设备、资源类型（岗位）、默认执行岗位、默认门禁、转移条件、**化验方案清单**、可选过程记录模板。

**化验方案（替代独立取样点表）：**

| 字段     | 规则                                                   |
| -------- | ------------------------------------------------------ |
| 业务类型 | 生产过程检 / 成品检（展示：过程化验/产出化验）         |
| 化验类型 | 过程：投料前核对 / 中控取样 / 转序放行；成品：产出化验 |
| 门禁     | `record` 记录 · 不挡确认；`hard` 硬门禁 · 确认前须合格 |
| 允许多次 | 默认可再次发起                                         |

**确认本步：** 仅校验本步过程检硬门禁方案最新结果为合格；成品检不挡确认。批次「化验」为过程检清单（状态 + 发起），产出化验在「产出」过账生成。

**参数：** 配方阶段自定义参数行 + 工序过程记录模板；不强制 temp/time/rpm/ph 四键。

**未落地：** 独立 `samplePoints`（dose/release）、参数上下限硬卡确认、化验公式行等待实测后再过账。

## 7. 计划排产

审核通过的需求不再拆零件工单，也不再算齐套缺口。需求物料必须有一张生效配方。

整批配方：批次数 `N = ceil(需求量 / 基准批量)`。每一批都按完整基准批量下达，不生成尾数批。需求 100、基准批量 30 时生成 4 张批次指令，每张理论投料、理论产出、联产品与副产品预期数量都按 30 计算。

槽次配方：计划仍可按 `ceil(需求量 / 基准批量)` 生成指令，每张先按基准批量占罐。最后一张允许改成剩余需求量，只要大于 0 且不超过罐容。连续线不走这条拆法，日目标用第 7.1 节的投料计划。班长也可以不经过需求，直接开一张槽次：选择生效配方、确认所在罐；本次数量和体积可以后补。

生产计划按供应型态分流：「生成批次指令」（自制）、「生成外协订单」（外协，可带发料参考量）、「生成采购申请」（外购）。不再生成总装、部装、加工工单。

销售订单仍可驱动生产，只生成成品的批次计划，不生成零件工单、设计任务或 EBOM。

库存预警保留。成品或中间体可用库存低于最低库存时生成批次计划。补货台账记批次计划，不记零件缺口。库存下限不是连续线的唯一开工条件。

原料价格不进入计划模型，系统不判断该不该买、该不该增产。日投料目标由人填写。

### 7.1 投料计划

连续线按线维护投料计划，不把日目标拆成「今天一张、做完再关」的批次指令。

| 字段       | 规则                                             |
| ---------- | ------------------------------------------------ |
| 线         | 必填，对应一张生效配方。酸浸、水浸各算一条线     |
| 期间       | `month` 月、`week` 周、`day` 日                  |
| 目标投料量 | 必填，大于 0。单位用配方主原料的主单位           |
| 实投       | 不另记账。汇总该线、该期间内槽次上主原料的实加量 |

月计划拆到周，周计划拆到日。下一级目标之和可以不等于上一级，差记在计划上，不自动改槽次。有原料才排的线，没有日目标就不投，不补一条 0。

完成率 = 期间实投 / 期间目标。产出可以晚于投料入账，不要求日计划在当天产出后关闭。槽次仍按第 8 节单独开：一天多槽就是多张执行中的指令，各自占罐。班长也可以不挂日计划，直接开槽次。

## 8. 生产管理：批次指令

生产工单菜单改为「批次指令」。一张指令对应一个批次号。数量是批量（kg、L 或 m³），不是排产件数。一张槽次只代表这个槽这一次，不代表整条线当天的金属平衡。

状态沿用 **待下发、执行中、完成**。执行中包含等待化验和槽内补加，不另设状态。

当前主路径：下发时数量即按基准批量确认并生成理论投料快照。槽次「数量先空、执行中补记、完结确认卡罐容」见第 4.1 节，**未落地**。

第一期在 Web 录入。班长在交班或本步放行时记本步合计。同一物料在本步的每一轮补加仍分开记数量。不要求每个工人随手记每一笔。

完成必须同时满足（当前）：

1. 各步已确认（过程硬门禁已过）。
2. 实际投料已记账。
3. 产出已按处理方式过账。

**未落地：** 主元素检测齐全且收率已算出；槽次数量完结确认。

执行中记这些内容：

| 记录     | 内容                                                                                                                             |
| -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 实际投料 | 原料批次、实加量、含量、阶段；理论量见 `theoreticalFeeds`                                                                        |
| 步骤参数 | 确认本步写入的参数实绩与过程记录模板字段                                                                                         |
| 化验     | 过程检挂 `stepQcMap`；产出检挂 `outputQcRecords`                                                                                 |
| 得率     | 主产品实际产出相对理论产出的质量得率差                                                                                           |
| 异常偏差 | 整单字段 `deviation` + `deviationLogs`；产出登记「补充」有值才追加并刷新最新，留空不改；基本信息与「产出与追溯」均展示，可看历史 |

详情：**投料明细**、**批记录**、工艺阶段、产出与追溯（含异常偏差、物料平衡、待判定确认去向、再提等；**不做批令成品放行**）。

投料按功能参数选手选批 / 库位 FIFO / Either，可展示指导量（按含量折算）；产出过账按 disposition 生成批次/入库、进暂存（不立刻入库）、待回用/待再提/废弃；**产出化验在过账后按勾选生成**；批次可用性 = 生产入库确认 + 硬门禁结论（若有）。

补加：同物料多次投料累加轮次。**计划外投料字段未单独建模**（可补加配方外物料时以现场补加行为为准，待补文档级字段）。

打印：**批次标签**（打到批次，不打袋/桶）。

### 8.1 主元素收率

**未落地（二期）。** 规划：投入 = Σ 投料×批次主元素含量；回流单列不进分母；产品/渣/尾液按元素去向；收率 = 产品/投入。

### 8.2 期间金属平衡

**未落地（二期）。** 规划：班/日/周/月；投入/回流/产品/渣/尾液/在制；在制未测不把缺口算损失。

## 9. 库存

批次在原有字段上补：

| 字段       | 规则                                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 批次状态   | 启用效期：`pending` 待检、`released` 合格、`concession` 让步接收、`rejected` 不合格、`expired` 过期。未启用效期：没有 `expired` |
| 生产日期   | 可空；采购收货、产出入库时写入                                                                                                  |
| 失效日期   | 仅启用效期的物料。由生产日期 + 保质期带出，可改                                                                                 |
| 含量       | 批次实测值。现场按含量折算时优先手填、否则读这里；不以配方假定含量回落。开折算且没有含量不能过账                                |
| 检测项     | `{ 检验项, 值, 单位 }` 列表。化验公式、主元素收率、混罐加权都读这里                                                             |
| 所在位置   | 仓库 / 库位。库位类型为货位、储罐或料仓                                                                                         |
| 直接父批次 | 拆批、混罐领出时记录一层                                                                                                        |
| 回流标记   | 来自元素去向为回流的产出时为是                                                                                                  |

投料和发货只能使用合格或让步接收的批次。让步接收的含量以实测值为准，折价记在收货行，不改库存数量。物料启用效期时，还要求失效日期晚于今天，默认近效期先出。待检、不合格不能投、不能发。过程补加中的在制指令不是不合格批次。

按单占用可以留作可选，不再是主规则。

盘点对象改成批次和罐存，按重量或体积盘。保住身份的罐按批次盘；混罐按结存数量盘，盘盈盘亏改结存，不恢复历史来源。启用主元素时，固体和液体都可以把结存折成同一当量，用来对期间在制。盘点不清空产线。

停用下料结算、余料回库、完工库存扣减记录。库存移动为：

| 移动     | 何时记账                                              |
| -------- | ----------------------------------------------------- |
| 投料消耗 | 投料或补加指定原料批次并确认                          |
| 产出入库 | 某步产出行过账到仓库                                  |
| 入罐     | 某步产出行过账到储罐                                  |
| 罐间转移 | 调拨。源是保住身份时指定批次；源是混罐时按第 5 节领出 |

## 10. 质量

来料质检、生产过程检、成品检、出厂质检、外协回货检保留。外协回货检对象改为外协收货产生的批次，检验方式与来料检相同。工序外协触发的回货检不做。

检验从「合格多少件」改为对规格上下限填实测值。模板上的检验项带标准值、下限、上限；任务上填实测值。

过程检按方案发起；硬门禁方案未合格则不能确认本步；记录型不挡确认。产出化验不挡确认本步。

来料检超限：不合格或让步接收；让步接收允许投料，含量记实测值。

| 检验     | 挂在哪（当前）                      | 通过后 / 约束                                                                               |
| -------- | ----------------------------------- | ------------------------------------------------------------------------------------------- |
| 来料检   | 采购/客供收货批次                   | 放行或让步后可投料                                                                          |
| 过程检   | 工序/阶段化验方案 → 批次化验清单    | 硬门禁：方案合格后可确认本步                                                                |
| 产出化验 | 配方产出行 → 产出过账勾选后生成检单 | 先过账再建单；回用/再提/确认去向须完成且未不合格；可用性靠入库确认+硬门禁，不做批令成品放行 |
| 出厂质检 | 发货/出库前                         | 待检、不合格不能发；启用效期时过期也不能发                                                  |

已入库后不合格：部分报废或开返工指令，不回到原槽次。

**上一步中控取样提示：** 只读、不拦截；门禁只由本步过程硬门禁控制。

## 11. 返工与再提

过程补加/复检留在原指令。

- **返工：** 已入库批次再加工，记前/后批次。
- **再提：** 产出 disposition=`reextract`（或待判定后再定）→ `await_reextract` → 开再提指令。
- **回用：** disposition=`reuse` → `await_reuse` → 投料选回流料；产出化验硬门禁适用。

## 12. 采购、外协、销售、小程序

单据尽量沿用现有菜单，只改规则。

**采购收货。** 用于外购、客供到货。收货行必须产生原料批次，记下供应商批号、生产日期；物料启用效期时再记效期。状态默认待检。来料检放行或让步接收后才允许投料。按含量结算的物料，一车一批，收货必须写实测含量。低于合同含量时可以让步接收，折价记在收货行。外协收回不走采购收货。

### 12.1 外协（流程型）

离散外协（外协件 + 齐套 + 按件发料 + 工序外协）不带进流程型。流程型外协针对「整段外发加工」：本厂有配方或规格，把原料/辅料发出去，外厂加工后再收回。典型：火法外协烧料。

| 环节       | 规则                                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------------------- |
| 外协订单   | 挂供应商、收回物料（可关联生效配方）、约定含量或约定转化率。发料行按配方投料量带出参考量（kg/L），现场按批次实发 |
| 外协发料   | 选合格或让步接收批次出库扣库存，必须挂外协单。启用效期时不能发过期批次。不做齐套、不按件数 BOM                   |
| 外协收货   | 收回加工后物料，生成待检批次；记约定含量、实测浸出、转化率（实测 ÷ 约定）                                        |
| 外协回货检 | 规则同来料检；放行或让步接收后才能被后续投料选中                                                                 |
| 对账与追溯 | 一张单可多次发、多次收。明细对照已发量、已收量、转化率。收回批次可打开外协单和发出批次                           |

不做：工序外协、装配齐套、按件外协工单。纯买回的料走外购 + 采购收货。

**销售发货。** 只发已放行批次。让步接收只用于原料，不用于成品发货。物料启用效期时只发未过期批次，按近效期先出；未启用效期时按入库时间先出。随货配件、按单生产挂标不做。成品只有一种袋重时，袋数用重量除以袋重，不建包装规格。

**小程序。** 不再领任务、报件数、算工资。第一期在 Web 由班长录入，时点是交班或本步放行，记本步合计。小程序后接时沿用同一粒度，不按工人领任务。现场步骤：

1. 选一张执行中的批次指令。
2. 填本步过程参数。超限保留本轮。硬放行的步骤等待补加；只记录的步骤可以继续。
3. 扫原料批次，录入投料量。只能选合格或让步接收批次；启用效期时还要未过期。
4. 查看取样结果。硬放行且结论为待补加时，录入补加数量后再次取样。
5. 本步按门禁确认后，才能申请本步产出过账。只记录的步骤超限也可以确认。

审核、放行结论的改判、作废留在 Web。第一期 Web 上要能完成同样的投料、补加和产出过账，小程序可以后接；规则以本节为准。

## 13. 追溯

追溯串起原料批次、批次指令、产出批次、联产品、副产品和返工前后批次。

- 从原料批次看到它投进了哪些批次指令、多少量，含每一轮补加。
- 从产出批次看到指令、配方版本、步骤、每笔原料批次和投料量、取样轮次、实际产出、质量得率；启用主元素时看到收率，以及同指令的联产品、副产品批次。
- 从返工指令看到前批次与后批次。
- 从混罐领出批次看到直接来源和数量，只一层。
- 回流在收率里单列，追溯不沿回流继续展开。

本期不建立袋号、桶号，也不做从包装单元发起的投诉反查。

## 14. 工程变更

第一期不做。若后续保留 ECN / ECR，变更对象改为**配方版本**（哪张配方从哪个版本升到哪个版本），不沿用现有 BOM 子件替换和图纸变更。已下达的批次指令仍用下达时的配方快照，不受升版影响。

## 16. 第一期验收（对照当前原型）

1. 配方可保存并发布。基准批量、理论得率、投料量/配比、按含量折算与理论投料列、损耗、产出角色（含回收料/废弃物）、产出工序与产出化验勾选可保存。无下料尺寸、无多层子配方。
2. 按含量折算：配方含量生成理论投料；现场过账缺手填/批次含量则不能过账该行。
3. 批次指令可从待下发到执行中再到完成；步骤未确认、投料未记账、产出未过账时不能完成。
4. 过程化验清单可按方案发起；硬门禁未合格不能确认本步；产出化验在产出过账生成，回用/再提前校验。
5. 产出处理方式支持待判定/仓库/储罐/回用/再提/废弃；再提可开再提指令。
6. 投料只能选合格或让步接收批次；启用效期时拦截过期。
7. 采购/外协收货 → 待检 → 放行或让步后可投料；外协发收回可对照。
8. 销售发货不发待检/不合格成品；让步接收不用于成品发货。
9. 菜单不出现工时、报工工资、工业标识、齐套、拆解/总装/质检工单、工序外协等离散能力。

**明确未纳入本期验收（二期）：** 配方整批/槽次与所在罐、槽次数量待确认、化验公式投料、主元素收率、期间金属平衡、产出化验合格后才允许过账、独立取样点 dose/release 模型、流程型路线强制单工序串行保存校验。

## 17. 本期不做

- 包装单元，以及从袋、桶发起的投诉反查。成品只有一种袋重时，袋数用重量除以袋重
- 设备点检、保养、维修和数据采集
- 按原料价格自动排产。日投料目标由人填写
- 循环罐的水平衡优化。期间金属平衡见第 8.2 节（**二期**，当前未落地）
- 交接班快照、设备占用冲突校验。交班只是班长录入的时点，不做独立交接班单据
- 工程变更
