# 流程型 MES：配方、批次指令与批次库存

**日期：** 2026-11-17（补流程型外协发收回；文件名沿用 11-11 初稿路径）  
**仓库：** i-doms-web（`MES-for-PROCESS`）；小程序规则见第 12 节，单据仍在 Web 审核  
**状态：** 设计稿，待确认后改代码

当前系统按离散件制造建模：母件用几件子件、多层 BOM、下料尺寸、件工单、齐套、计件工资，批次只表示「这批货属于哪张销售单」。流程型生产是**一张配方对应一次配料或一个槽次**，数量是批量（kg、L 或 m³）。库存按批次状态放行；效期是否参与放行由物料决定。储罐是否保住批次身份由储罐自己的配置决定。

连续运转的湿法线仍用槽次指令表达一个槽的一次进料，用混罐表达中转和母液回流。日计划是投料计划，不是当天一张指令、做完再关。回收率按期间金属平衡看，不要求当天投入当天产出。

单据尽量沿用现有菜单，改规则、改对象，不平行再做一套单据。路由一期不改，避免已打开页签失效。

同一套能力覆盖配料和多段反应，靠配置组合，不按单个工厂写死流程。

| 配置       | 配料（食品、涂料、日化、精细化工） | 多段反应（浸出、净化、反应釜串联）                           |
| ---------- | ---------------------------------- | ------------------------------------------------------------ |
| 批量规则   | 整批：每张指令等于基准批量         | 槽次：可先占罐，执行中补数量，不超过罐容                     |
| 计划       | 按需求向上取整生成整批指令         | 按线维护投料计划。日目标不拆成关闭型工单                     |
| 投料计算   | 投料量、配比，或按含量折算         | 另可按化验公式现算。前段实加可以不等于计算量                 |
| 过程不合格 | 留在本指令补加、复检，直到放行     | 前段只记录。后段和入库不合格不能转出                         |
| 储罐       | 默认保住批次身份                   | 反应槽保住身份；中转罐、母液罐、循环罐按现场选保住身份或混罐 |
| 得率       | 质量得率                           | 指令上可结主元素收率。周、月看期间金属平衡                   |
| 效期       | 按物料打开                         | 多数物料关闭                                                 |

## 1. 分期

### 第一期

1. 配方可发布（版本、发布、生效），可维护联产品、副产品，产出可指定落到哪一步、去仓库还是去储罐。
2. 整批配方可按基准批量向上取整生成整批指令。连续线另维护投料计划（月、周、日）。槽次可先占罐再生产，数量在执行中补记，转出时大于 0 且不超过罐容。
3. 投料时指定原料批次并过账。计算方式为投料量、配比、按含量折算、按化验公式四选一。
4. 过程超限留在本指令，不另开返工单。门禁为硬放行的步骤，不合格不能确认，也不能把该步产出转出。门禁为只记录的步骤，超限留下轮次，仍可确认。
5. 产出入库，结质量得率。配方启用主元素时，同时结指令上的主元素收率，并按班、日、周、月结期间金属平衡。联产品、副产品随对应步骤入库。
6. 批次有状态。物料启用效期时才有失效日期，并参与投料和发货拦截。
7. 储罐、料仓维护罐容。库存方式二选一：保住批次身份，或混罐。罐间转移按量过账，不能超过罐容。
8. 追溯能串起原料批次、指令、产出、联产品、副产品、返工前后批次。混罐只展开直接来源一层。回流不重复计入收率分母。
9. 已入库的批次需要再加工时，对原批次开返工指令，记下前批次与后批次。
10. 采购收货、外协收货都必须产生待检批次。来料/外协回货放行或让步接收后才能投料。按含量结算的物料，收货必须写实测含量。外协收货可记转化率。
11. 外协按流程型保留：订单 → 按批次发原料/辅料 → 收回加工后物料 → 外协回货检。不做齐套、不做工序外协。

第一期不做工程变更，不做包装单元（袋、桶）和投诉反查。小程序规则见第 12 节。Web 上要先能完成同样的投料、补加、放行、产出入库和外协发收回。

## 3. 产品与物料

现有计划策略是 `mto` / `mts` / `mto_mts`（`src/mock/productInfoOptions.js`）。改为两项：

| 值      | 文案     | 含义                                               |
| ------- | -------- | -------------------------------------------------- |
| `batch` | 按批生产 | 销售或手工需求驱动，生成批次指令                   |
| `stock` | 备库存   | 成品或中间体低于最低库存时，由库存预警生成批次计划 |

已存 `mto` 迁到 `batch`，`mts` 与 `mto_mts` 迁到 `stock`。只有「备库存」必填最低库存。

主单位用重量或体积（kg、L、m³）。第二单位、储存条件可维护；空值显示 `—`。保质期、复验期仅在启用效期时必填。产品主数据不维护含量，也不单设密度。重量和体积要换算时，在辅助单位上填默认换算率。配方、入库、发货不读密度。

成品、联产品和副产品的实测含量不固定，不做成含量 SKU。含量只记在批次上。合格档次（如工碳、电碳）工艺和标准都不同时，各建一个产品；同一档次里 98.6% 和 99.1% 仍是这个产品。计划和配方指向产品，不指向某个含量点。销售按批次实测含量或档次取价。

| 字段     | 规则                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------- |
| 启用效期 | 否为默认。为是时，批次写失效日期；投料和发货拦截过期批次，并按近效期先出                                    |
| 检验项   | 来自检验项库。一个物料可有多项。批次上按检验项记实测值                                                      |
| 供应型态 | `自制` 本厂产线；`外购` 直接采购；`外协` 本厂有配方/规格，原料发出外厂加工后收回；`客供` 客户来料不产生采购 |

工时配置、下料结算、图号、材质改为可空，保存不拦截。

未启用效期的物料没有过期状态。投料和发货只看合格状态，出库顺序按入库时间。

## 4. 配方（原产品 BOM）

菜单与详情标题改为「配方」。状态机不动：待发布 → 生效 → 归档。同一物料同时只有一个生效版本。发布、升版、归档沿用 `productBomStore`。

### 4.1 表头

| 字段     | 规则                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 批量规则 | `full` 整批，或 `charge` 槽次                                                                        |
| 基准批量 | 必填，大于 0。单位用主产品主单位                                                                     |
| 所在罐   | 槽次必填，指向一台库存方式为「保住身份」的储罐，罐容单位与基准批量一致                               |
| 理论得率 | 未启用主元素时必填，0～1。理论产出 = 基准批量 × 理论得率                                             |
| 主元素   | 可空。启用时指定一个检验项。理论得率改记主元素收率目标（0～1），质量理论产出改由产出行的预期数量表达 |
| 产出     | 至少一条主产品，且必须等于配方所属物料。联产品、副产品追加行                                         |

整批：下达数量必须等于基准批量。槽次：下达数量大于 0，且不超过所在罐罐容；理论投料中的固定量和配比按 `下达数量 / 基准批量` 缩放。化验公式不按这个比例缩放。

槽次开立时，下达数量和体积可以先空着，执行中按实投累加。主原料数量在转出或完结时确认，确认值必须大于 0 且不超过所在罐容。数量未确认前，固定量和配比的参考量显示为待确认；化验公式仍按体积和实测值计算。同一天、同一配方可以开多张槽次，每张占自己的反应槽。

### 4.2 产出行

| 字段     | 规则                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------- |
| 角色     | `main` 主产品、`co` 联产品、`by` 副产品                                                            |
| 物料     | 必填                                                                                               |
| 预期数量 | 相对一个基准批量。槽次下达时按同一比例缩放                                                         |
| 发生步骤 | 必填，对应路线步骤。该步放行并确认后才过账这条产出                                                 |
| 去向     | `warehouse` 仓库，或 `tank` 储罐                                                                   |
| 元素去向 | 未启用主元素时为空。启用后取 `product` 产品、`slag` 渣、`tail` 尾液、`recycle` 回流、`none` 不计入 |

一条指令可以在同一步过账多条产出。滤液进储罐、滤渣进仓库，是同一槽次上的两条产出行，不另开指令。

### 4.3 投料明细

去掉母件用量（件）、下料尺寸、下料面积、面积换算、子件 BOM 引用。

| 字段       | 规则                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 物料       | 必填                                                                         |
| 计算方式   | `qty` 投料量、`ratio` 配比、`content` 按含量折算、`assay` 化验公式。四者互斥 |
| 投料量     | 计算方式为投料量时必填，相对一个基准批量                                     |
| 配比       | 计算方式为配比时必填，相对基准批量，0～1                                     |
| 损耗       | 比例，默认 0。化验公式不使用损耗                                             |
| 含量检验项 | 按含量折算时必填                                                             |
| 化验系数   | 化验公式时必填，大于 0                                                       |
| 化验检验项 | 化验公式时必填。计算量 = 系数 × 该检验项最近一轮实测值 × 体积                |
| 投料顺序   | 正整数，同序号允许并列                                                       |
| 发生步骤   | 必填                                                                         |

一个基准批量下的参考量：

- 投料量：`投料量 × (1 + 损耗)`
- 配比：`基准批量 × 配比 × (1 + 损耗)`
- 按含量折算：上式中的投料量或配比结果再 ÷ 含量。含量只取被投批次的实测值。批次没有含量不能过账
- 化验公式：下达时没有参考量。体积取指令上的体积；单位已是 L 或 m³ 时，体积默认等于下达数量，可改

槽次指令把前三种参考量再乘 `下达数量 / 基准批量`。

### 4.4 不再展开多层

下达、打印、详情只展示本配方这一层。中间体做成独立物料、独立配方。父配方投料行只引用中间体物料，不挂子配方，下达时也不自动拆中间体指令。

上一指令的产出进入仓库或储罐后，下一指令把它当作原料批次领用。

昨天的料还在后段、今天已经在前段投新料，用多张执行中的槽次加上混罐衔接，不用一张指令串起整条线。

历史树形 BOM 不迁移。本地数据版本号加一，旧结构丢弃并重新种子化。

## 5. 储罐与库存方式

位置类型仍为货位、储罐、料仓。储罐和料仓增加：

| 字段     | 规则                                     |
| -------- | ---------------------------------------- |
| 罐容     | 必填，大于 0                             |
| 运行上限 | 可空，大于 0 且不超过罐容。空则只卡罐容  |
| 单位     | 与罐内物料主单位一致                     |
| 库存方式 | `identity` 保住批次身份，或 `blend` 混罐 |

液位等于罐内结存数量，不能超过罐容。超过罐容的转入、产出过账都拒绝。结存超过运行上限时允许过账，并给出提示。连续线常用罐容的大约三分之二作为运行上限，留出约三分之一空位。

**保住批次身份。** 罐内按批次分列。转移必须指定源批次和数量。部分转移时拆出新批次，继承状态、含量、检测项、效期，并记下直接父批次。反应槽使用这种方式，槽次指令的在制批量占着这台罐，直到产出转出。

**混罐。** 转入不保留来源批次在罐内的独立身份。罐存是一个结存数量，另记直接来源：来源批次、数量、转入时间。从混罐领出时生成新批次：

- 数量为本次领出量
- 状态取这些直接来源里最严的一档：有待检则为待检，否则有让步接收则为让步接收，否则为合格；来源里有不合格时禁止领出
- 检测项按来源数量加权
- `parents` 只记录这一层直接来源
- 启用效期时，失效日期取来源里最早的一个

混罐的来源如果本身也是混罐领出批次，追溯展示到该领出批次为止，不再往更早的来源展开。循环罐、母液罐、汇流罐用混罐；需要分批存放的配料罐、成品罐用保住身份。两种方式可以出现在同一租户的不同储罐上。

## 6. 工艺路线与工序

一条配方挂一条路线。路线按步串行，每一步只有一道单元操作（投料、升温、保温、过滤、灌装），名称来自工序配置，不写死枚举。

离散网格里「同一步多道并行工序」和列头「全部完成 / 选做完成」不用于流程型。流程型路线保存时，同一个 `stepNo` 只允许一道工序。工厂里同时进行的工作，用下面三种方式表达，不在一张指令里开并行分支。

| 现场现象                                 | 处理                                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------------------------- |
| 同一槽次里先反应、再取样、再过滤         | 同一条路线上的先后步骤。上一步确认后才能做下一步                                       |
| 压滤后滤液和滤渣各走各的，两条线同时在跑 | 仍是这一步的两条产出。后续各用自己的配方另开指令，指令之间没有先后锁，所以可以同时执行 |
| 同一种料有酸法、水浸、火法等不同制法     | 每种制法一张配方、一条路线。开指令时选定配方，一张指令只走其中一条                     |
| 同一配方有多台罐一起生产                 | 多张批次指令，每张占自己的反应槽。路线不复制                                           |

分流之后要汇合时，汇合发生在下一张指令的投料：从对应仓库或储罐领用上游产出。混罐按第 5 节合并来源；保住身份的罐则指定具体批次。不在路线上画汇合节点。

标准参数挂在步上：温度、时间、转速、pH，各有设定值、下限、上限。填了上下限时，下限 ≤ 设定值 ≤ 上限。四个都空表示该步不控这些参数。

标准四项以外的参数（液位、压力、比重、固液比、洗涤时间等）走工序表单模板，不写死进产品。模板字段为字段名、类型、单位、是否必填、可选上下限。路线每步可选一个启用模板。该步需要标准四项以外的参数时，必须选择模板。

步骤上可配置取样点：

| 字段       | 规则                                                       |
| ---------- | ---------------------------------------------------------- |
| 编码、名称 | 必填                                                       |
| 用途       | `dose` 用于计算化验公式，或 `release` 用于放行。可同时两种 |
| 质检模板   | 必填                                                       |
| 必选       | 是 / 否                                                    |

步骤增加门禁，二选一：

| 值       | 文案   | 规则                                                                                                         |
| -------- | ------ | ------------------------------------------------------------------------------------------------------------ |
| `record` | 只记录 | 超限保留本轮。实加量可以先过账，不必等化验公式算出计算量。必选取样点要有实测值，超限不阻止确认，产出仍可过账 |
| `hard`   | 硬放行 | 沿用下面的完成条件。超限不能确认，不能过账该步产出。化验公式行要等实测值算出计算量之后才能过账               |

前段反应用只记录。后段净化和成品入库用硬放行。

硬放行的步骤完成同时满足：

1. 设了上下限的标准参数和模板字段，实际值落在上下限内。超限时本步不能确认，补加或调整后另记一次实际值。没有上下限的参数只记录。
2. 本步投料行都已过账。化验公式行要等对应取样点有实测值，算出计算量之后才能过账。
3. 本步每个必选、用途含 `release` 的取样点已放行。

只记录的步骤仍要记下参数、实加量和取样实测值。超限不锁死确认。下一步加多少由现场决定，系统留下理论量和实加量供对照。

现有列头「完成方式」（全部完成 / 选做完成）从流程型路线编辑去掉，不参与批次完成判定。

工序配置保留编码、名称、分类、备注、资源类型、默认执行。资源类型为下拉单选，一期仅「岗位」便于扩展；选岗位时默认执行取岗位主数据，不挂班组或具体人（岗位稳定、换班领任务）。从编辑里拿掉：报工类型、计件单价、计薪口径、作业分项、下料、拆解、工序外协。

## 7. 计划排产

审核通过的需求不再拆零件工单，也不再算齐套缺口。需求物料必须有一张生效配方。

整批配方：批次数 `N = ceil(需求量 / 基准批量)`。每一批都按完整基准批量下达，不生成尾数批。需求 100、基准批量 30 时生成 4 张批次指令，每张理论投料、理论产出、联产品与副产品预期数量都按 30 计算。

槽次配方：计划仍可按 `ceil(需求量 / 基准批量)` 生成指令，每张先按基准批量占罐。最后一张允许改成剩余需求量，只要大于 0 且不超过罐容。连续线不走这条拆法，日目标用第 7.1 节的投料计划。班长也可以不经过需求，直接开一张槽次：选择生效配方、确认所在罐；本次数量和体积可以后补。

生产计划按供应型态分流：「生成批次指令」（自制）、「生成外协订单」（外协，可带发料参考量）、「生成采购申请」（外购）。不再生成总装、部装、加工工单。

销售订单仍可驱动生产，只生成成品的批次计划，不生成零件工单、设计任务或 EBOM。

库存预警保留。成品或中间体可用库存低于最低库存时生成批次计划。补货台账记批次计划，不记零件缺口。库存下限不是连续线的唯一开工条件。

原料价格不进入计划模型，系统不判断该不该买、该不该增产。日投料目标由人填写。

### 7.1 投料计划

连续线按线维护投料计划，不把日目标拆成「今天一张、做完再关」的批次指令。

| 字段       | 规则                                             |
| ---------- | ------------------------------------------------ |
| 线         | 必填，对应一张生效配方。酸浸、水浸各算一条线     |
| 期间       | `month` 月、`week` 周、`day` 日                  |
| 目标投料量 | 必填，大于 0。单位用配方主原料的主单位           |
| 实投       | 不另记账。汇总该线、该期间内槽次上主原料的实加量 |

月计划拆到周，周计划拆到日。下一级目标之和可以不等于上一级，差记在计划上，不自动改槽次。有原料才排的线，没有日目标就不投，不补一条 0。

完成率 = 期间实投 / 期间目标。产出可以晚于投料入账，不要求日计划在当天产出后关闭。槽次仍按第 8 节单独开：一天多槽就是多张执行中的指令，各自占罐。班长也可以不挂日计划，直接开槽次。

## 8. 生产管理：批次指令

生产工单菜单改为「批次指令」。一张指令对应一个批次号。数量是批量（kg、L 或 m³），不是排产件数。一张槽次只代表这个槽这一次，不代表整条线当天的金属平衡。

状态沿用 **待下发、执行中、完成**。执行中包含等待化验和槽内补加，不另设状态。

整批指令的下达数量在下发时就等于基准批量。槽次的下达数量可以在执行中补记，完结前必须确认，规则见第 4.1 节。

第一期在 Web 录入。班长在交班或本步放行时记本步合计。同一物料在本步的每一轮补加仍分开记数量。不要求每个工人随手记每一笔。

完成必须同时满足：

1. 各步已确认。
2. 实际投料已记账。
3. 各产出行已按去向过账。
4. 启用主元素时，投入和主产出的该检验项都有值，收率已算出。

执行中记这些内容：

| 记录     | 内容                                                             |
| -------- | ---------------------------------------------------------------- |
| 实际投料 | 原料批次、参考量、计算量、实加量、是否计划外                     |
| 步骤参数 | 标准四项和模板字段的实际值；超限后的每一轮都保留                 |
| 取样     | 取样点、轮次、实测值、结论                                       |
| 补加     | 哪一轮取样或哪一次参数超限触发，物料、数量、时间                 |
| 得率     | 未启用主元素时，主产品实际产出相对理论产出。启用主元素时另记收率 |
| 异常偏差 | 文本或数值，可空                                                 |

详情页原「领料信息」改为 **投料明细** 和 **批记录**。批记录按步骤列出参数实际值、取样轮次、投料批次、确认人、确认时间。

投料当时指定原料批次并过账，库存立即减少。产出在所属步骤放行并确认时过账：去仓库的生成库存批次，去储罐的按该罐的库存方式转入。三种旧扣减模式整段替换。

补加使用本步已有投料行，实加量累加，并保留每一轮数量。需要加入配方以外的物料时，记一笔计划外投料，计入实际消耗；启用主元素时计入投入。计划外投料不回写配方。

打印从工单工序码改为 **批次标签**（批次号、物料、批量、生产日期、状态；启用效期时加失效日期）。本期标签打到批次，不打到袋或桶。

拆解工单、总装工单、质检工单不迁。质检走质量菜单。

### 8.1 主元素收率

启用主元素时：

- 投入 = Σ（投料量 × 该原料批次上主元素检验项的值）。计划外投料同样计入
- 回流投入单列，不计入投入。判定规则：该原料批次来自元素去向为回流的产出，或来自混罐领出且其直接来源中带有回流标记的那一部分数量
- 产品量 = 元素去向为产品的产出数量 × 产出批次上该检验项的值
- 渣、尾液按元素去向分别合计，用于平衡，不进入收率分母
- 收率 = 产品量 / 投入

检测项单位以配方指定的检验项为准。缺实测值时指令不能完成。

### 8.2 期间金属平衡

指令收率回答这一槽次收了多少。周报和月结回答这一段时间收了多少。连续线上，今天过账的渣常常来自昨天的投料，不用当天指令收率代替期间收率。

期间取班、日、周、月。一条线一张平衡。未启用主元素的配方不做这张表，仍只结质量得率。

| 项             | 取数                                                              |
| -------------- | ----------------------------------------------------------------- |
| 投入           | 期间内投料数量 × 原料批次上主元素检验项。让步接收的批次用实测含量 |
| 回流投入       | 同第 8.1 节，单列，不进分母                                       |
| 产品、渣、尾液 | 期间内过账的产出 × 产出批次上该检验项，按元素去向汇总             |
| 在制           | 期末罐存和管道结存中的主元素，减去期初。固体、液体折成同一当量    |
| 收率           | 产品 / 投入。在制单独列出，用来解释投料和产出不在同一天           |

盘点停线测罐存即可，不清空产线。缺在制实测时，期间收率仍按投入和已过账产出计算，在制标成未测，不把缺口算成损失。

## 9. 库存

批次在原有字段上补：

| 字段       | 规则                                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 批次状态   | 启用效期：`pending` 待检、`released` 合格、`concession` 让步接收、`rejected` 不合格、`expired` 过期。未启用效期：没有 `expired` |
| 生产日期   | 可空；采购收货、产出入库时写入                                                                                                  |
| 失效日期   | 仅启用效期的物料。由生产日期 + 保质期带出，可改                                                                                 |
| 含量       | 批次实测值。按含量折算只读这里。没有实测值不能过账                                                                              |
| 检测项     | `{ 检验项, 值, 单位 }` 列表。化验公式、主元素收率、混罐加权都读这里                                                             |
| 所在位置   | 仓库 / 库位。库位类型为货位、储罐或料仓                                                                                         |
| 直接父批次 | 拆批、混罐领出时记录一层                                                                                                        |
| 回流标记   | 来自元素去向为回流的产出时为是                                                                                                  |

投料和发货只能使用合格或让步接收的批次。让步接收的含量以实测值为准，折价记在收货行，不改库存数量。物料启用效期时，还要求失效日期晚于今天，默认近效期先出。待检、不合格不能投、不能发。过程补加中的在制指令不是不合格批次。

按单占用可以留作可选，不再是主规则。

盘点对象改成批次和罐存，按重量或体积盘。保住身份的罐按批次盘；混罐按结存数量盘，盘盈盘亏改结存，不恢复历史来源。启用主元素时，固体和液体都可以把结存折成同一当量，用来对期间在制。盘点不清空产线。

停用下料结算、余料回库、完工库存扣减记录。库存移动为：

| 移动     | 何时记账                                              |
| -------- | ----------------------------------------------------- |
| 投料消耗 | 投料或补加指定原料批次并确认                          |
| 产出入库 | 某步产出行过账到仓库                                  |
| 入罐     | 某步产出行过账到储罐                                  |
| 罐间转移 | 调拨。源是保住身份时指定批次；源是混罐时按第 5 节领出 |

## 10. 质量

来料质检、生产过程检、成品检、出厂质检、外协回货检保留。外协回货检对象改为外协收货产生的批次，检验方式与来料检相同。工序外协触发的回货检不做。

检验从「合格多少件」改为对规格上下限填实测值。模板上的检验项带标准值、下限、上限；任务上填实测值。

过程检超限的默认结论是 **待补加**，不是批次不合格。后果看该步门禁：

| 结论   | 硬放行                                                               | 只记录                               |
| ------ | -------------------------------------------------------------------- | ------------------------------------ |
| 放行   | 该取样点本轮结束。用途含 `dose` 时，实测值可被化验公式使用           | 同左                                 |
| 待补加 | 本步不能确认，所属产出不能过账。补加过账后才能开下一轮取样           | 留下本轮。本步仍可确认，产出仍可过账 |
| 报废   | 只在明确不再加工时手工选择。按第 10 节报废过账，不作为超限的默认结果 | 同左                                 |

同一取样点保留每一轮实测。硬放行的步骤，全部必选放行点都放行后才能确认。只记录的步骤，必选点有实测值即可确认。

来料检超限时，原料批次可以判为不合格，也可以让步接收。不合格不能投料。让步接收允许投料，含量记实测值。

| 检验     | 挂在哪                                     | 通过后                                                             |
| -------- | ------------------------------------------ | ------------------------------------------------------------------ |
| 来料检   | 采购或委外收货产生的原料批次               | 批次改为合格或让步接收，才允许投料                                 |
| 过程检   | 批次指令某步的取样点                       | 硬放行：必选点放行后该步可确认。只记录：必选点有实测值后该步可确认 |
| 成品检   | 作为最后一步的放行取样点，挂在产出过账之前 | 产出行才允许过账                                                   |
| 出厂质检 | 已入库批次、发货前                         | 待检、不合格不能发；启用效期时过期也不能发                         |

已入库之后发现不合格，不再回到原槽次。处理方式是部分报废，或按第 11 节开返工指令。

收货后原料批次默认待检。没有来料放行或让步接收记录时，投料选择原料批次列表里不出现该批。

报废对象是批次，或该批次上的部分数量。报废过账把对应数量从可用批次扣掉。

**上一步中控取样结果提示（经验增强，不是门禁）**：打开下一步工序相关操作时，展示上一步中控取样状态（未发起 / 进行中 / 已出结果摘要），便于现场按结果调参数。不拦截本步确认或投料；门禁仍只由本步硬门禁方案控制。

## 11. 返工

过程中的补加、复检、参数重记都留在原批次指令，不打开返工单。

返工只用于已经入库的批次。对原批次开一张再加工指令，批量不超过原批次剩余量。完成后生成后批次，并记下前批次与后批次。原批次剩余量随再加工投料扣减。

## 12. 采购、外协、销售、小程序

单据尽量沿用现有菜单，只改规则。

**采购收货。** 用于外购、客供到货。收货行必须产生原料批次，记下供应商批号、生产日期；物料启用效期时再记效期。状态默认待检。来料检放行或让步接收后才允许投料。按含量结算的物料，一车一批，收货必须写实测含量。低于合同含量时可以让步接收，折价记在收货行。外协收回不走采购收货。

### 12.1 外协（流程型）

离散外协（外协件 + 齐套 + 按件发料 + 工序外协）不带进流程型。流程型外协针对「整段外发加工」：本厂有配方或规格，把原料/辅料发出去，外厂加工后再收回。典型：火法外协烧料。

| 环节       | 规则                                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------------------- |
| 外协订单   | 挂供应商、收回物料（可关联生效配方）、约定含量或约定转化率。发料行按配方投料量带出参考量（kg/L），现场按批次实发 |
| 外协发料   | 选合格或让步接收批次出库扣库存，必须挂外协单。启用效期时不能发过期批次。不做齐套、不按件数 BOM                   |
| 外协收货   | 收回加工后物料，生成待检批次；记约定含量、实测浸出、转化率（实测 ÷ 约定）                                        |
| 外协回货检 | 规则同来料检；放行或让步接收后才能被后续投料选中                                                                 |
| 对账与追溯 | 一张单可多次发、多次收。明细对照已发量、已收量、转化率。收回批次可打开外协单和发出批次                           |

不做：工序外协、装配齐套、按件外协工单。纯买回的料走外购 + 采购收货。

**销售发货。** 只发已放行批次。让步接收只用于原料，不用于成品发货。物料启用效期时只发未过期批次，按近效期先出；未启用效期时按入库时间先出。随货配件、按单生产挂标不做。成品只有一种袋重时，袋数用重量除以袋重，不建包装规格。

**小程序。** 不再领任务、报件数、算工资。第一期在 Web 由班长录入，时点是交班或本步放行，记本步合计。小程序后接时沿用同一粒度，不按工人领任务。现场步骤：

1. 选一张执行中的批次指令。
2. 填本步过程参数。超限保留本轮。硬放行的步骤等待补加；只记录的步骤可以继续。
3. 扫原料批次，录入投料量。只能选合格或让步接收批次；启用效期时还要未过期。
4. 查看取样结果。硬放行且结论为待补加时，录入补加数量后再次取样。
5. 本步按门禁确认后，才能申请本步产出过账。只记录的步骤超限也可以确认。

审核、放行结论的改判、作废留在 Web。第一期 Web 上要能完成同样的投料、补加和产出过账，小程序可以后接；规则以本节为准。

## 13. 追溯

追溯串起原料批次、批次指令、产出批次、联产品、副产品和返工前后批次。

- 从原料批次看到它投进了哪些批次指令、多少量，含每一轮补加。
- 从产出批次看到指令、配方版本、步骤、每笔原料批次和投料量、取样轮次、实际产出、质量得率；启用主元素时看到收率，以及同指令的联产品、副产品批次。
- 从返工指令看到前批次与后批次。
- 从混罐领出批次看到直接来源和数量，只一层。
- 回流在收率里单列，追溯不沿回流继续展开。

本期不建立袋号、桶号，也不做从包装单元发起的投诉反查。

## 14. 工程变更

第一期不做。若后续保留 ECN / ECR，变更对象改为**配方版本**（哪张配方从哪个版本升到哪个版本），不沿用现有 BOM 子件替换和图纸变更。已下达的批次指令仍用下达时的配方快照，不受升版影响。

## 16. 第一期验收

1. 配方可保存并发布。整批与槽次、基准批量、理论得率、四种投料计算、损耗、联产品和副产品、产出步骤和去向都能保存。没有下料尺寸，也没有多层子配方。按含量折算时，原料批次没有实测含量不能过账该行。
2. 整批配方在需求 100、基准批量 30 时生成 4 张指令，每张理论投料和理论产出都按 30 计算。
3. 槽次配方可手工开指令，开立时数量可以先空着。确认后的数量超过所在罐容时不能保存。数量小于基准批量时，固定量和配比按比例缩小，化验公式仍按实测值和体积计算。同一天同一配方可以有多张执行中的槽次。
4. 批次指令可从待下发到执行中再到完成。还有步骤未确认、投料未记账、产出未过账时不能完成。启用主元素但缺检测值时不能完成。槽次完结前数量必须大于 0。
5. 投料必须选择合格或让步接收批次。待检、不合格选不到。物料启用效期时，过期批次选不到，列表按近效期排列。未启用效期的物料不因日期被拦截。
6. 化验公式在取样实测值写入后得到计算量。实加量可以与计算量不同，两者都留在批记录里。只记录的步骤不必等计算量就能过账实加。
7. 硬放行的步骤，过程取样超限时该步不能确认，该步产出不能过账。补加并复检放行后可以确认。只记录的步骤，超限留下轮次后仍可确认、仍可过账。两种都不生成新的批次号，也不生成返工单。
8. 同一步的滤液入罐、滤渣入库分两条产出过账。去向罐为混罐时，罐内不再按来源批次分列；从此罐领出得到新批次，父批次只有直接来源。去向罐为保住身份时，产出批次在罐内保持独立。
9. 转入后超过罐容的过账被拒绝。结存超过运行上限时允许过账并提示。保住身份的罐间转移后，源批次数量减少，目标批次数量增加。
10. 启用主元素时，指令详情能看到投入、回流投入、产品量、渣、尾液和收率。回流投入不进收率分母。按日或按月能看到同一条线的期间平衡；在制未测时不把缺口算成损失。
11. 已入库批次可以开返工指令，完成后能从后批次打开前批次。过程补加不出现在返工菜单。
12. 采购收货保存后能看到待检原料批次。来料检放行后变为合格。低于合同含量可以让步接收，实测含量写在批次上，折价写在收货行。
13. 外协订单可按配方带出发料参考量；外协发料按批次扣库存；外协收货生成待检批次并可保存约定含量、实测浸出和转化率；外协回货检放行后该批可被投料选中。明细能对照已发量、已收量和转化率。
14. 销售发货不能发出待检批次，也不能把让步接收当成成品放行。启用效期的物料不能发出过期批次。
15. 从产出批次能打开投料明细、取样轮次和同指令的联产品、副产品。混罐领出批次只能再展开一层直接来源。外协收回批次能打开外协单和发出批次。
16. 菜单中不再出现工时、报工工资、工业标识、下料结算、齐套、设计任务、拆解工单、总装工单、质检工单、工序外协。外协订单/发料/收货/回货检按第 12.1 节保留。没有袋号、桶号和投诉反查入口。
17. 流程型路线每一步只能有一道工序。同一槽次不能配置并行分支；滤液和滤渣的后续加工必须分成各自的批次指令。
18. 连续线可保存日投料计划。实投由该线槽次的主原料实加量汇总。当天没有产出时，日计划不关闭。

- 工程变更
