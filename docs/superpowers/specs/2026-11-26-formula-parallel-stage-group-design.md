# 配方工艺阶段 · 并行组与汇合方式

**日期：** 2026-11-26  
**状态：** 已确认  
**范围：** 配方工艺阶段配置 + 批次指令「确认本步」顺序门禁（同批并行，不另开子指令）

## 1. 背景与目标

沉锂等湿法线在「一次净化」后液进二次浆化、渣进洗涤，需在**同一张批次指令**内表达分叉，并支持两种汇合：

| 汇合方式                      | 含义                                 |
| ----------------------------- | ------------------------------------ |
| **组内完成一条即可**（`any`） | 同组任一条确认后，可进入组后下一阶段 |
| **全部完成才汇合**（`all`）   | 同组全部确认后，才可进入组后下一阶段 |

配置放在**配方工艺阶段**上，不强制回到离散工艺路线网格。路线仍只管设备候选。

## 2. 数据模型

阶段 `steps[]` 增量字段：

| 字段              | 类型             | 说明                                           |
| ----------------- | ---------------- | ---------------------------------------------- |
| `parallelGroupId` | string           | 空 = 串行阶段；非空 = 同一并行组（如 `G2`）    |
| `joinMode`        | `'any' \| 'all'` | **挂在组上**：同组成员须一致；新建组默认 `any` |

落库仍用连续整数 `stepNo`（1…n）。界面可展示「同组并排」；序号仍用阶段序。

下发快照 `routeSnapshot` 原样带出上述字段，避免事后改配方影响在制单解释。

## 3. 执行规则（确认本步）

在现有「批次阶段时序确认」开启时：

1. **组外串行**：无 `parallelGroupId` 的阶段，须上一**串行序**已满足（见下）。
2. **组内并行**：同组阶段互不要求对方已确认；各自过程检硬门禁只卡本步。
3. **进入组后第一个非本组阶段**时：
   - `any`：同组至少 1 个 `stepNo` 已在 `confirmedSteps`
   - `all`：同组全部 `stepNo` 均已确认
4. **组内某一成员的「上一序」**：取组前最近一个串行阶段（或不属于本组的阶段），不取同组兄弟。
5. 时序开关关闭时：不拦并行汇合（与现网一致，仅硬门禁等仍生效）。

## 4. 配方编辑 UI

工艺阶段表增加列：

- **并行关系**（面向用户，不手填短码）：下拉「不并行」/「与上一阶段并行」/「加入并行：阶段A / 阶段B」。系统自动生成或复用内部 `parallelGroupId`。
- **汇合方式**：有并行关系时可选；同组同步；`any` / `all`

提示文案：液渣都要做完再往下 → `all`；本次只走一支 → `any`。

## 5. 种子

工业级碳酸锂默认配方：一次净化后「二次浆化 ‖ 氟渣洗涤」并行组，`joinMode=any`；后续沉锂等串行。
