# 工艺路线拓扑

## 业务背景与目标

现场连续线（如沉锂）不是纯串行格子：主线工序分出洗涤支线，多路渣/锂盐再进**压滤**，压滤往往**不在主线**上。旧「步号 × 并行行」网格表达不了，MOCK 还曾把压滤塞成主线第 3 步。

目标：工艺路线用**主线 + 支线 + 汇合点**描述工序流与候选设备；本期**不关联产线工段**；批次执行顺序仍以配方工艺阶段为准。

## 核心业务流程

1. 工艺路线编辑为三栏：左工序库拖拽、中大画板（默认 3 主线空格）、右工序信息/本格配置/文件。
2. 路径与连线：路径类型/分出/汇入/**回流**（在删除格按钮上方）→ 删除主线/支线格；本格配置：设备分类、候选设备、转移条件、**按化验方案逐行**门禁/本路线质检、工艺文件。
3. 网格与节点列表同一份 `nodes`（`ProcessRouteTopologyGridEditor`）。
4. 配方仍挂该路线；批次执行仍以配方阶段为准。分叉不再在配方配并行组；批令按路线 `pathKind` 识别支线，可对本单关闭。

## 关键业务规则与约束

- `layout(布局)`：`topology` | `grid`；有有效 `nodes` 时视为拓扑。
- 路径：`main(主线)` / `branch(支线)` / `sink(汇合点)`。
- **回流**：编辑时可加空草稿行；保存时 `pruneEmptyReturns` 丢掉未填项。
- **化验方案覆盖**：工序 `qcConfigs` 有几条，本路线就几行；每行 `qcOverride(继承/本路线不检)` + `gateMode(跟随方案/记录/硬门禁)`。某方案「不检」时清空该行门禁。无 `assayOverrides` 时兼容旧整格 `gateCustom`/`qcOverride`。
- **添加支线节点**：选中主线 → 新开并行支线；选中支线 → 再分出下级（分出=该支线）。
- **删除两段**：有工序时 × 只清空工序；空格再点才删整格。
- **布局**：主线支线落在两个主线格之间；子支再右下；汇入最底。无汇合点时不默认汇入为主线。
- 支线必填：`branchName`、`forkAfterNodeId`；有汇合点时首格须填汇入。

## 数据模型与接口关联

| 字段                                       | 含义                                         |
| ------------------------------------------ | -------------------------------------------- |
| `nodes[].processId`                        | 工序                                         |
| `nodes[].equipmentIds`                     | 候选设备                                     |
| `nodes[].forkAfterNodeId` / `joinToNodeId` | 支线分出 / 汇入                              |
| `nodes[].branchLineId`                     | 同一条支线上多节点共用；新开支线默认=自身 id |
| `nodes[].returns`                          | 回流（stream + toNodeId）                    |
| `nodes[].assayOverrides[]`                 | 按 `qcConfigId` 覆盖门禁与是否质检           |
| MOCK `GYLX0012`                            | 主线不含压滤；氟渣/钙镁渣/锂盐洗涤 → 压滤    |

入口：`src/utils/processRouteTopology.js`、`ProcessRouteTopologyGridEditor.vue`、`processRouteSeed.js`。

## AI 与开发维护要点

- 设备收集：`collectTopologyEquipmentIds`。
- 方案合并：`resolveAssaySchemesForRouteNode` → 工单快照 `assaySchemes`；`qcTriggerService.resolveProcessQcConfigs` 优先用快照。
- 删除：`removeRouteNode`。
- 产线拓扑是另一套产能模型，本期不与路线节点互相关联。
