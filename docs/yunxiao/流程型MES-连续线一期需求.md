# 流程型 MES · 一期功能需求

更新日期：2026-11-18

对应设计：`docs/superpowers/specs/2026-11-11-process-formula-batch-plan-design.md`

每条可在云效单独建需求。标题用功能名，说明贴需求说明。

含量不拆 SKU：计划和配方都指向产品。工碳、电碳这种合格档次不同、工艺也不同时，各建一个产品。同一产品产出后含量仍会浮动，记在批次上，销售按批次实测含量或档次取价。

---

## 产品主数据

**需求说明**

产品信息保留，作为配方、计划和库存的物料。流程型不再按件维护。

1. 计划策略改为两项：按批生产、备库存。只有备库存必填最低库存。原来的按单、备货、按单兼备货分别归入这两项。
2. 主单位用重量或体积（kg、L、m³）。检验项可以维护。不维护含量，含量只记在批次上。不单设密度。重量和体积要换算时，在辅助单位上填默认换算率。配方、入库、发货不使用密度。
3. 不按实测含量拆 SKU。98.6% 和 99.1% 不是两个产品。合格标准不同、工艺也不同的档次才分开建产品，例如工业级碳酸锂和电池级碳酸锂。
4. 启用效期默认否。启用后才维护保质期，批次写失效日期，投料和发货拦截过期批次。
5. 工时、下料、图号、材质改为可空，保存不拦截。
6. 供应型态四项：**自制**（本厂产线）、**外购**（直接采购）、**外协**（本厂有配方或规格，原料发出去外厂加工后再收回）、**客供**（客户来料，不产生采购）。外协不是工序外协，也不是离散的外协件拆工单。

## 配方管理

**需求说明**

产品 BOM 改为配方。菜单和详情都叫配方。状态仍是待发布、生效、归档，同一物料同时只有一个生效版本。

1. 表头维护批量规则（整批或槽次）、基准批量、理论得率。槽次要指定所在罐，罐必须是保住批次身份的储罐。
2. 启用主元素时，指定一个检验项，理论得率改记这个元素的收率目标。质量产出改由产出行的预期数量表达。
3. 投料行四选一：投料量、配比、按含量折算、化验公式。按含量折算只用原料批次的实测含量，批次没有含量不能过账。化验公式按取样实测值和体积现算，不按批量比例缩放。
4. 主产品、联产品、副产品都是产品主数据里已经建好的物料，配方里从列表选择，不手填名称。主产品有且只有一条，并且必须是这张配方所属的物料。联产品、副产品追加行，指定发生步骤、进仓库还是进储罐，以及元素去向（产品、渣、尾液、回流、不计入）。
5. 中间体做成独立物料、独立配方。本配方只引用这个物料，下达时不自动拆下一层指令。滤液和滤渣是同一步的两条产出，不另开配方。
6. 去掉母件用量、下料尺寸、子件 BOM。历史树形 BOM 不迁移。
7. 投料行可以指定所属工艺阶段。批次做到该阶段投料时，默认只带出挂在这一步的物料和理论量。未指定阶段的行不默认带出，现场仍可补加。

## 工艺路线

**需求说明**

一条配方挂一条路线。路线按步串行，同一步只允许一道单元操作，名称来自工序配置。

1. 工序维护默认门禁和默认转移条件。只记录：超限留下轮次，实加可以先过账，本步仍可确认。硬放行：超限不能确认，也不能把该步产出转出。前段默认只记录，后段净化和成品入库默认硬放行。路线引用时带出。路线未改则跟随工序默认；路线改过的只属于该路线。从路线生成工单时，把当时生效的门禁和转移条件抄到工单工序上。
2. 步骤可维护温度、时间、转速、pH 的设定值和上下限。液位、压力、比重等走工序表单模板，需要这些参数时必须选一个启用的模板。
3. 步骤可配置取样点，用途是计算投料、放行，或两者都要，并挂质检模板。硬放行的步骤，必选放行点都合格后才能确认。只记录的步骤，必选点有实测值即可确认。
4. 酸浸、水浸、火法各做一张配方、一条路线。后段汇合发生在下一张指令从罐或仓库领用，不在路线上画汇合。
5. 工序配置维护编码、名称、分类、操作说明、允许设备、**资源类型**、**默认执行**、默认门禁、默认转移条件。允许设备从设备台账多选，可以不填。资源类型为下拉单选，一期选项仅「岗位」（字段保留便于后续扩展其它类型）；选岗位时，默认执行从基础配置岗位主数据选取，支持边搜边选、多选，并提供「选择更多」弹窗。工序列表展示被引用数，按引用该工序的路线条数计算，同一条路线出现多次只算 1。去掉报工类型、计件单价、计薪口径、作业分项、下料、拆解、工序外协。完成方式（全部完成 / 选做完成）不参与流程型判定。

   **为何一期默认执行只取岗位、不挂班组或具体人：** 流程型现场按岗位领任务、换班交接；挂到具体人会在交班后无人可领，挂到班组则无法落到终端的岗位任务池。岗位稳定、人不稳定——谁在岗谁领，与排班无关。资源类型下拉预留扩展口，但默认执行的岗位口径不变。

## 产线管理

**需求说明**

一个工厂可有多条产线。产线是排产、执行、分发任务的产能单元，不是单纯的车间名称。

1. 产线主数据维护编码、名称、所属车间、状态、备注，以及**有序工段**。设备与岗位挂在工段上，不再在产线根级扁平多选。新增/编辑在**新标签页**打开（工段表 + 拓扑预览，不用弹窗）。
2. **工段有顺序**：按工艺顺序添加、上移/下移；主线工段序号连续。每个工段可选多台设备、多个岗位（1 工段 : N 设备/岗位，不要求设备与岗位一一对应）。
3. **产线可有分支**：工段路径分「主线 / 支线」。支线须指定支线名称、从哪个主线工段后分出、汇入哪个主线工段前（汇合可不填，视为线末）。列表展示拓扑摘要；编辑时展示主线 + 支线拓扑预览。
4. **生产计划必挂产线**。同一配方、同一期间，不同产线可各有一条计划；唯一性按「配方 + 期间 + 产线」。拆下级计划时继承上级产线。
5. **批次 / 槽次指令挂产线**：从计划开启时带出计划产线；列表与详情展示产线。后续现场任务按该线工段关联岗位分发，设备选用优先落在该线工段挂的设备上（硬约束可二期加强）。
6. 产线停用后不可再被新计划选用；已挂历史计划与批次保留展示。
7. 不做：把产线当成工艺路线的替代；路线仍描述怎么做，产线描述在哪套产能上做。不做产线内复杂并行网（多进多出图编辑）；一期仅主线 + 可标注的支线分出/汇合。
8. 设备称谓统一为「设备」（与设备台账一致）。产线工段、配方阶段选设备支持边搜边选与「选择更多」。
9. 配方工艺阶段：可先选**设备分类**，再**多选候选设备**；执行/开槽次以计划产线工段设备为准，配方候选为默认范围。
10. **投料计划不选工艺路线**：选配方 + 产线即可；路线挂在配方上，随配方带出阶段结构。

## 储罐与库位

**需求说明**

库位类型仍为货位、储罐、料仓。储罐和料仓增加罐容、单位、运行上限、库存方式。

1. 保住批次身份：罐内按批次分列。反应槽用这种方式，槽次没转出前占着这台罐。部分转移时拆出新批次，带上状态、含量和检测项。
2. 混罐：罐内不保留来源批次。母液罐、中转罐、汇流罐用混罐。领出时生成新批次，检测项按来源数量加权，只记录这一层直接来源。来源里有不合格则不能领出；有待检则领出批次为待检；否则有让步接收则为让步接收。
3. 结存不能超过罐容，超过的转入和产出直接拒绝。运行上限可空，建议约为罐容的三分之二。超过运行上限允许过账，并给出提示。
4. 罐间转移走调拨。源罐保住身份时要指定批次；源罐是混罐时按领出规则生成新批次。

## 生产计划

**需求说明**

生产计划不再拆零件工单，也不算齐套。新增时先选主产品，再在该产品已生效的配方里选择；一个产品可以有多张配方，有默认配方时先带出默认配方，仍可改选。不为联产品、副产品单独下计划。产出含量等化验完成后再写到批次上。

1. 整批配方：批次数等于需求量除以基准批量后向上取整。每一张都按完整基准批量下达，不生成尾数批。例如需求 100、基准批量 30，生成 4 张，每张按 30 计算。
2. 连续线不走这条拆法。按配方维护投料计划，期间为月、周、日，也可自定义起止日期，目标投料量由人填写，**必须选择产线**。计划编号可手填，未填按系统规则生成；计划名称默认为「期间 + 期间类型 + 计划」，可改。选了配方并填写目标投料量后，按配方理论得率算出理论产出（目标投料量 × 理论得率）。实投汇总该期间该产线槽次上主原料的实加量，不另记一笔账。下一级目标之和可以不等于上一级。当天没有产出，日计划不关闭。
3. 有原料才生产的线（如水浸）没有日目标就不排。系统不根据原料价格建议投多少。
4. 销售订单只生成成品的批次计划。库存低于最低库存时也生成批次计划，写入补货台账，不记零件缺口。库存下限不是连续线的唯一开工原因。
5. 计划按供应型态分流：自制生成批次指令；外协生成外协订单（可带发料参考量）；外购生成采购申请。连续线的日目标不自动拆成指令，槽次由现场另开并继承计划产线。不再生成总装、部装、加工工单。
6. 计划详情的过程指标中，联产品、副产品各占一张卡。先按该计划配方的产出明细画出联产品和副产品；配方里有、尚未入库时数量为 0。本计划及下级挂靠批次已经产出入库、而配方明细里没有的联产品或副产品，再自动补一张卡。数量按这些批次已入库实收加总，同一物料多次入库合并。卡片写角色和物料编码、名称。回收料、废弃物不在这组卡片里。

## 外协（流程型）

**需求说明**

保留外协订单、外协发料、外协收货、外协明细菜单，按流程型改规则。典型场景：火法整段外发——本厂配好料、发出原料和辅料，外厂加工后收回，本厂记转化率后再进水浸。

1. 外协订单挂供应商、收回物料（可关联生效配方）、约定含量或约定转化率。发料行按配方投料量带出参考量（重量/体积），现场按批次实发，实发可以和参考量不同，两者都留痕。
2. 外协发料按原料/辅料批次出库扣库存，必须挂在外协订单上。只能发合格或让步接收批次；启用效期时不能发过期批次。不做齐套、不按件数 BOM 发料。
3. 外协收货收回加工后物料，生成待检批次；记约定含量、实测浸出和转化率（实测 ÷ 约定）。一车一批时分开堆放。质检走外协回货检（规则同来料检：上下限 + 实测，可让步接收）。放行或让步接收后才能被后续投料选中。
4. 一张外协订单可多次发料、多次收货。明细能对照：已发原料量、已收回量、转化率。追溯能从收回批次看到对应外协单和发出批次。
5. 不做：工序外协（工单某一步外发）、装配齐套、按件外协工单。纯买回来的料仍走外购 + 采购收货，不走外协。

## 批次指令

**需求说明**

生产工单改为批次指令。一张指令一个批次号，数量是重量或体积，不是件数。状态仍为待下发、执行中、完成。执行中包含等待化验和槽内补加。

1. 整批指令下发时数量就等于基准批量。槽次选定配方和反应槽后可以先占罐，下达数量和体积先空着，执行中按实投累加，转出或完结时再确认。确认值必须大于 0 且不超过罐容。数量未确认前，固定量和配比显示待确认。
2. 同一天、同一配方可以有多张执行中的槽次，每张占自己的反应槽，并挂所属产线。昨天的料还在后段、今天已经在前段投料，用多张槽次加上混罐，不用一张指令串起整条线。
3. 第一期在 Web 录入。班长在交班或本步放行时记本步合计，每一轮补加分开记数量。不要求每个岗位随手记账；任务分发可按产线工段关联岗位。
4. 完成要同时满足：各步已按门禁确认，投料已记账，各产出行已过账，启用主元素时投入和主产出都有检测值并且收率已算出。
5. 详情把原领料信息改为投料明细和批记录。批记录按步骤列出参数、取样轮次、投料批次、确认人和确认时间。打印改为批次标签（批次号、物料、批量、生产日期、状态），不打到袋或桶。

## 投料

**需求说明**

领料管理改为投料。投料当时指定原料批次并过账，库存立即减少。原来的不领料、完工预扣、自主领料三种扣料方式停用。

1. 只能选择合格或让步接收、且未过期的批次。待检、不合格不出现在可选列表。启用效期的物料按近效期先出。
2. 参考量按配方计算。整批相对基准批量；槽次在数量确认后按「下达数量 ÷ 基准批量」缩放。按含量折算再除以该批次含量。化验公式在对应取样点有实测值之后才有计算量。
3. 实加量可以和参考量、计算量不同，两笔都留下。只记录的步骤不必等计算量就能过账实加。
4. 补加使用本步已有投料行，数量按轮次累加。需要加入配方以外的物料时，记计划外投料，计入实际消耗，不回写配方。
5. 投料按原料批次扣减，从而把这一车的含量带进成本和收率。不能按物料合计估数出库。

## 联副产品与产出

**需求说明**

成品入库改为按步骤产出。产出发生在该步按门禁确认之后，不是整张指令结束时一次性入库。

1. 主产品、联产品、副产品按配方产出行过账。去仓库的生成库存批次，去储罐的按该罐的库存方式转入。同一步的滤液入罐、滤渣入库，分两条产出，不另开指令。
2. 产出批次写入实测含量和检测项。含量以这次化验为准，不回写产品主数据，也不要求等于某个 SKU。低于该产品合格标准时不能当作合格成品放行。
3. 未启用主元素时，结主产品实际产出相对理论产出的质量得率。启用主元素时，另结收率：产品金属量 ÷ 投入金属量。回流投入单列，不进分母。渣和尾液参加平衡，不进分母。
4. 副产品按种类入库，含量写在该批次上，后续是销售、回用还是再提，按含量决定，不在配方里拆成多个含量产品。

## 期间金属平衡

**需求说明**

指令收率只说明这一槽次。周报和月结另看一条线在一段时间里的金属平衡。今天过账的渣可以来自昨天的投料。

1. 期间为班、日、周、月。启用主元素的线才出这张表。
2. 投入取期间投料数量乘原料批次的主元素含量。回流单列。产品、渣、尾液取期间已过账产出。在制取期末罐存和管道结存减去期初，固体和液体折成同一当量。
3. 收率等于产品除以投入。在制单独列出。在制未测时仍算出投入和已过账产出，在制标成未测，不把缺口算成损失。
4. 盘点停线测罐存即可，不清空产线。测到的结存用来填在制。

## 质量检验（化验）

**需求说明**

来料、过程、成品、出厂检验保留（菜单与页面展示名统一为「化验」向命名，内部业务类型值可保持兼容）。检验从「合格多少件」改为按模板上下限填实测值，同一取样点保留每一轮。

1. 过程超限的默认结论是待补加，不是批次不合格。硬放行的步骤因此不能确认、不能产出；只记录的步骤留下本轮后仍可确认。报废只能手工选择，不作为超限的默认结果。
2. 成品检挂在最后一步产出过账之前。合格标准是档次区间，例如工碳不低于 98.5%。实测含量落在区间内即放行，并把实测值写到产出批次。落在区间外不能按这个产品放行。
3. 来料超限可以判不合格，也可以让步接收。让步接收写入实测含量，允许投料。
4. 已入库之后发现不合格，不回到原槽次。处理是部分报废，或对原批次开返工指令。
5. 外协回货检保留，对象是外协收货产生的批次；检验方式与来料检相同（上下限 + 实测，可让步接收）。不恢复工序外协触发的回货检。
6. **上一步中控取样结果提示（经验增强，不是门禁）**：打开下一步工序相关操作（确认本步、投料、发起化验等）时，若上一步配置了「中控取样」或已有对应检单，给出只读提示：`上一步中控取样：未发起 / 进行中 / 已出结果：xxx`（xxx 为化验结论及关键实测值摘要）。便于现场按结果调参数。**不拦截、不阻止**本步确认或投料；硬卡/门禁仍只由本步「转序放行」等硬门禁方案控制，不因本提示新增门禁模型。
7. **化验模板 · 过程化验须维护化验类型**：业务类型为过程化验时，模板必填化验类型（投料前核对 / 中控取样 / 转序放行），列表与详情同步展示。发起化验时按业务类型 + 化验类型 + 物料 + 工序匹配模板（精确类型优先，兼容未填类型的旧模板）。

## 采购收货

**需求说明**

采购收货单据保留，用于**外购**和**客供**到货。保存后必须产生原料批次，状态默认待检。没有放行或让步接收记录时，不能被投料选中。

1. 按含量结算的原料一车一批，分开堆放。收货必须写实测含量，作为结算和以后投料折算的依据。供应商提供的含量不能直接当成批次含量。
2. 低于合同含量可以让步接收。批次含量用实测值，折价记在收货行，不改库存数量。不合格批次不能投料。
3. 外协收回不走采购收货，走外协收货（见「外协」一节）。采购收货不再用「委外加工」来源顶替外协闭环。
4. 启用效期的物料同时记生产日期和失效日期。

## 库存、调拨与盘点

**需求说明**

入库、出库、库存明细的单据保留。批次补充状态、含量、检测项、位置、生产日期和直接父批次。状态为待检、合格、让步接收、不合格；启用效期的物料再加过期。

1. 投料和原料出库可以使用合格、让步接收的批次。成品发货只能使用合格批次。待检、不合格不能投、不能发。
2. 调拨执行罐间转移，不能超过罐容。混罐领出不恢复更早的来源。
3. 盘点对象改为批次和罐存。保住身份的罐按批次盘，混罐按结存盘，盘盈盘亏只改结存。启用主元素时，结存可折成同一当量，供期间在制使用。不清空产线。
4. 停用下料结算、余料回库、完工按 BOM 件数扣库，以及库存扣减记录。库存移动保留投料消耗、产出入库、入罐、罐间转移、外协发料出库、外协收回入库。

## 返工

**需求说明**

过程中的补加、复检、参数重记都留在原批次指令，返工菜单里看不到。

返工只用于已经入库的批次。对原批次开再加工指令，数量不超过剩余量。完成后生成后批次，并记下前批次与后批次。原批次剩余量随再加工投料扣减。

## 销售发货

**需求说明**

销售订单和发货单据保留。订单行选择产品并写计价方式，不选择含量，也不手填一个含量品名。下单时通常还不知道这批货会化验成多少。

1. 按档次一口价：订单写死单价。发货只能选达到该产品合格标准的批次。98.6% 和 99.1% 用同一个价，含量只打印在发货和质检单上。
2. 按含量计价：订单写基准含量、基准单价、含量每高或低一档加减多少钱。订单金额先按基准含量估算。发货时选定已放行批次，用该批次实测含量套这条规则算出结算单价。一车有多批时，按每批的重量分别计价，再合计。
3. 结算重量用过磅净重。价格只按批次实测含量或档次计算。让步接收不用于成品。启用效期时，过期批次不能发。
4. 不做随货配件，不做按单生产挂标。成品只有一种袋重时，袋数用发货重量除以袋重。本期不建包装规格，也不做到袋号。

## 批次追溯

**需求说明**

从原料批次能看到它投进了哪些指令、多少量，含每一轮补加；也能看到它是否发给了外协、对应哪张外协单。从产出批次能看到指令、配方版本、步骤、每笔原料和含量、取样轮次、实际产出、得率，以及同指令的联产品、副产品。启用主元素时能看到收率。外协收回批次能打开外协单、发出批次和转化率。

混罐领出的批次只能再展开一层直接来源。回流在收率里单列，追溯不沿回流继续往前展开。返工能从后批次打开前批次。

本期不建立袋号、桶号，也不做从包装单元发起的投诉反查。

## 工艺参数单位

**需求说明**

工艺参数单位与库存、采购、包装用的单位管理分开。温度、时间、转速、压力、流量这些单位不进库存，也不做公斤和升的换算。

1. 基础配置单独维护工艺参数单位。字段有编码、单位符号、类别、备注、启用状态。类别包括温度、时间、转速、压力、流量、酸碱、电气、其他。
2. 预置 ℃、min、h、s、rpm、pH、MPa、kPa、%、m³/h、L/min、A、Hz。允许新增。符号不能重复。
3. 配方工艺阶段的参数单位从启用的工艺参数单位中选择。停用或删除后，新参数不能再选；已经写在配方上的符号保持原样。
4. 单位只作为批记录上的文字，不参与投料数量换算。
