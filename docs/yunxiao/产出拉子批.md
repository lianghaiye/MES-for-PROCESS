# 产出拉子批（下游指令）

## 业务背景与目标

主线与支线配成多张配方时：主线登渣/副产后，再开支线批令去做洗涤等，投料预填该产出批。

## 核心业务流程

1. 配方产出行启用「生成下游指令」，多选下游配方，选开单方式。
2. 主线登产出建批后：
   - **手动生成**：点「开支线指令」；多个下游时先选配方。
   - **自动**：仅 1 个下游时可开；过账成功即生子令。
3. 子令待下发，数量默认=本行产出量。

## 关键业务规则与约束

| 方式         | 时机                 | 多下游                     |
| ------------ | -------------------- | -------------------------- |
| 手动生成     | 人工点「开支线指令」 | 弹窗选配方                 |
| 过账后自动开 | 产出过账成功         | **不允许**（强制改为手动） |

## 数据模型与接口关联

| 字段                                          | 含义          |
| --------------------------------------------- | ------------- |
| `downstreamFormulaIds`                        | 下游配方列表  |
| `downstreamSpawnMode`                         | manual / auto |
| `createBranchOrderFromOutput(..., formulaId)` | 生成子令      |
